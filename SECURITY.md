# Politique de sécurité

## Signaler une vulnérabilité

Dans GitHub, ouvrez **Security and quality** (ou **Security**), puis **Advisories** et **Report a vulnerability**. Le signalement privé permet au mainteneur de vérifier et de corriger le problème avant une éventuelle publication.

Indiquez la version ou le commit de File Transformer, votre version de Windows, votre version de Python et les étapes de reproduction. Utilisez exclusivement des fichiers fictifs. N’ajoutez jamais de clés, de données personnelles ni de documents ou images privés.

Pour un défaut ordinaire sans enjeu de sécurité, utilisez **Issues**.

## Versions suivies

Les correctifs sont préparés sur la branche principale `main`. Vérifiez si le problème persiste sur cette branche.
